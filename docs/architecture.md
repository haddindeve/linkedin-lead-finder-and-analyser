# LinkedIn Lead Finder and Analyser - architecture

A command-driven research workspace: defined commands for sourcing, research and briefing, so the same steps run in the same order every time. The output is a structured brief rather than a pile of raw profile text.

## Components

### Research commands

Defined, repeatable research operations

### Sourcing

Prospect discovery and shortlisting

### Analysis

Fit assessment against a target profile

### Briefing

Structured output for the salesperson

## Stack

| Layer | Technology |
| --- | --- |
| Automation | Agent command workflows |
| Research | LinkedIn profile and company analysis |
| Output | Structured prospect briefs |
