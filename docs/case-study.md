# LinkedIn Lead Finder and Analyser - case study

**Engineer:** Muhammad Tanveer - Full-Stack AI Automation Engineer  
**Repository:** https://github.com/haddindeve/linkedin-lead-finder-and-analyser

## Context

Researching a prospect on LinkedIn - profile, company, recent activity, fit - takes ten to fifteen minutes per lead and is done differently by each person doing it.

## What I built

A command-driven research workspace: defined commands for sourcing, research and briefing, so the same steps run in the same order every time. The output is a structured brief rather than a pile of raw profile text.

## Capabilities delivered

- Repeatable research commands
- Prospect sourcing and shortlisting
- Fit analysis against a target profile
- Structured briefs instead of raw notes

## Outcome

- Per-prospect research reduced to a single command
- Consistent output regardless of who runs it
