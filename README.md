## The problem

Researching a prospect on LinkedIn - profile, company, recent activity, fit - takes ten to fifteen minutes per lead and is done differently by each person doing it.

## The approach

A command-driven research workspace: defined commands for sourcing, research and briefing, so the same steps run in the same order every time. The output is a structured brief rather than a pile of raw profile text.

## Architecture

| Component | Responsibility |
| --- | --- |
| **Research commands** | Defined, repeatable research operations |
| **Sourcing** | Prospect discovery and shortlisting |
| **Analysis** | Fit assessment against a target profile |
| **Briefing** | Structured output for the salesperson |

## FAQ

### What does it produce?

A structured brief per prospect - profile summary, company context and fit assessment.

### Is it a scraper?

Sourcing is one step; the value is the analysis and briefing built on top.

### Can the research steps be changed?

Yes - the workflow is defined as commands that can be edited or extended.
